## 03.1 | 관계형 데이터베이스 개요

**데이터베이스**는 여러 사람이 함께 쓰려고 모아 둔 데이터 묶음이고, 이를 관리하는 프로그램을 **DBMS**라고 해요. 그중 데이터를 **표(테이블)** 형태로 저장하고 테이블끼리 관계로 잇는 것이 **관계형 데이터베이스(RDBMS)**입니다. (Oracle, MySQL, SQL Server, PostgreSQL 등)

| 용어 | 뜻 |
|---|---|
| 테이블 (릴레이션) | 행과 열로 된 데이터 저장 단위 |
| 행 (Row, 튜플) | 데이터 하나 (사원 한 명) |
| 열 (Column, 속성) | 데이터의 항목 (이름, 급여) |
| 기본키 (PK) | 행을 유일하게 구분하는 칼럼 |
| 외래키 (FK) | 다른 테이블의 PK 를 참조하는 칼럼 |

### SQL 명령의 종류

| 종류 | 명령어 | 하는 일 |
|---|---|---|
| DML (조작어) | SELECT, INSERT, UPDATE, DELETE, MERGE | 데이터 조회·변경 |
| DDL (정의어) | CREATE, ALTER, DROP, RENAME, TRUNCATE | 테이블 등 구조 정의 |
| DCL (제어어) | GRANT, REVOKE | 권한 부여·회수 |
| TCL (트랜잭션 제어어) | COMMIT, ROLLBACK, SAVEPOINT | 트랜잭션 확정·취소 |

> 💡 SELECT 를 따로 **DQL**(질의어)로 나누기도 해요. TRUNCATE 는 데이터를 지우지만 **DDL** 이라는 점이 시험에 자주 나옵니다.

```sql
-- 예제 데이터베이스의 세 테이블 맛보기
SELECT * FROM DEPT;
```

## 03.2 | SELECT 문

```sql norun
SELECT [DISTINCT] 칼럼, 식 [AS 별칭]      -- ⑤ 무엇을 보여 줄까
FROM 테이블                                -- ① 어디서
WHERE 조건                                 -- ② 어떤 행을
GROUP BY 칼럼                              -- ③ 어떻게 묶을까
HAVING 그룹 조건                           -- ④ 어떤 그룹을
ORDER BY 칼럼 [ASC|DESC];                  -- ⑥ 어떤 순서로
```

> 💡 **실행 순서**: FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY. 그래서 SELECT 에서 만든 **별칭은 WHERE 에서 쓸 수 없지만 ORDER BY 에서는 쓸 수 있어요.**

```sql
-- 칼럼 고르기, 계산식, 별칭
SELECT ENAME AS 이름, SAL AS 월급, SAL * 12 AS 연봉 FROM EMP WHERE DEPTNO = 10;
```

```sql
-- DISTINCT: 중복 행 제거
SELECT DISTINCT JOB FROM EMP;
```

```sql
-- 합성 연산자 || 로 문자열 잇기 (SQL Server 는 +)
SELECT ENAME || '의 업무는 ' || JOB || '입니다' AS 소개 FROM EMP WHERE DEPTNO = 10;
```

!> 별칭에 공백이나 특수문자가 있으면 큰따옴표로 감싸요: `SAL * 12 AS "연 봉"`. 작은따옴표는 문자열 값에만 씁니다.

## 03.3 | 함수(Function)

함수는 **단일행 함수**(행마다 결과 하나)와 **다중행 함수**(여러 행에서 결과 하나, 집계 함수)로 나뉘어요. 여기서는 단일행 함수를 봅니다. 오라클은 테이블 없이 계산만 할 때 **DUAL** 테이블을 써요.

### 문자 함수

| 함수 | 결과 예 |
|---|---|
| LOWER / UPPER / INITCAP('sql exPERT') | sql expert / SQL EXPERT / Sql Expert |
| LENGTH('SQLD') | 4 |
| SUBSTR('SQL Expert', 5, 3) | Exp (5번째부터 3글자) |
| INSTR('SQL Expert', 'E') | 5 (처음 나오는 위치) |
| LPAD('7', 3, '0') / RPAD | 007 |
| LTRIM / RTRIM / TRIM | 왼쪽·오른쪽·양쪽 공백(문자) 제거 |
| REPLACE('ABCB', 'B', 'X') | AXCX |
| CONCAT('A', 'B') | AB (인수 2개) |

```sql
SELECT UPPER('sqld') AS U, INITCAP('sql exPERT') AS I, LENGTH('SQLD') AS L,
       SUBSTR('SQL Expert', 5, 3) AS S, INSTR('SQL Expert', 'E') AS P,
       LPAD('7', 3, '0') AS PAD, REPLACE('ABCB', 'B', 'X') AS R
FROM DUAL;
```

### 숫자 함수

| 함수 | 결과 예 |
|---|---|
| ROUND(123.456, 1) / ROUND(123.456, -1) | 123.5 / 120 |
| TRUNC(123.456, 1) / TRUNC(-1.5) | 123.4 / -1 (버림) |
| CEIL(1.1) / FLOOR(1.9) | 2 / 1 |
| MOD(7, 3) | 1 (나머지) |
| ABS(-5) / SIGN(-5) | 5 / -1 |

```sql
SELECT ROUND(123.456, 1) AS R1, ROUND(123.456, -1) AS R2, TRUNC(123.456, 1) AS T1,
       CEIL(1.1) AS C, FLOOR(-1.1) AS F, MOD(7, 3) AS M, SIGN(-5) AS S
FROM DUAL;
```

### 날짜 함수 (오라클)

| 함수 | 뜻 |
|---|---|
| SYSDATE | 현재 날짜·시간 |
| 날짜 + 1 / 날짜 - 날짜 | 하루 뒤 / 두 날짜 사이 일수 |
| ADD_MONTHS(날짜, n) | n 개월 뒤 |
| EXTRACT(YEAR FROM 날짜) | 연도만 꺼내기 |
| TO_CHAR(날짜, 'YYYY-MM-DD') | 날짜 → 문자 |
| TO_DATE('2026-11-04', 'YYYY-MM-DD') | 문자 → 날짜 |

```sql norun
SELECT SYSDATE, SYSDATE + 1, ADD_MONTHS(SYSDATE, 3), TO_CHAR(SYSDATE, 'YYYY"년" MM"월"')
FROM DUAL;                         -- 오라클 전용 (실행 시점마다 결과가 다름)
```

> 💡 **변환**에는 명시적 변환(TO_CHAR, TO_NUMBER, TO_DATE 등 함수 사용)과 암시적 변환(DBMS 가 알아서 바꿈)이 있어요. 암시적 변환은 인덱스를 못 쓰게 만들 수 있어 명시적 변환이 권장됩니다.

### NULL 관련 함수

| 함수 | 뜻 | 예 → 결과 |
|---|---|---|
| NVL(a, b) | a 가 NULL 이면 b | NVL(NULL, 0) → 0 |
| NVL2(a, b, c) | a 가 NULL 이 아니면 b, NULL 이면 c | NVL2(COMM, 'Y', 'N') |
| NULLIF(a, b) | a = b 이면 NULL, 아니면 a | NULLIF(5, 5) → NULL |
| COALESCE(a, b, c…) | 처음으로 NULL 이 아닌 값 | COALESCE(NULL, NULL, 3) → 3 |

```sql
SELECT ENAME, COMM, NVL(COMM, 0) AS NVL, NVL2(COMM, '있음', '없음') AS NVL2,
       NULLIF(SAL, 1250) AS NULLIF, COALESCE(COMM, MGR, 0) AS COAL
FROM EMP WHERE DEPTNO = 30;
```

### CASE 와 DECODE

```sql
-- 검색형 CASE: 조건에 따라 다른 값
SELECT ENAME, SAL,
       CASE WHEN SAL >= 3000 THEN '고액'
            WHEN SAL >= 1500 THEN '중간'
            ELSE '일반' END AS 등급,
       DECODE(DEPTNO, 10, '회계', 20, '연구', '기타') AS 부서        -- 오라클 DECODE
FROM EMP WHERE DEPTNO IN (10, 20);
```

> 💡 `DECODE(표현식, 값1, 결과1, 값2, 결과2, 기본값)` 은 `CASE 표현식 WHEN 값1 THEN 결과1 … ELSE 기본값 END` (단순형 CASE) 와 같아요. ELSE 가 없으면 NULL 이 나옵니다.

## 03.4 | WHERE 절

WHERE 절은 **원하는 행만 골라내는 조건**이에요.

| 연산자 | 뜻 | 예 |
|---|---|---|
| = , <> (!=, ^=) , > , >= , < , <= | 비교 | SAL >= 3000 |
| BETWEEN a AND b | a 이상 b 이하 | SAL BETWEEN 1000 AND 2000 |
| IN (목록) | 목록 중 하나 | DEPTNO IN (10, 20) |
| LIKE '패턴' | 패턴 일치 (% 여러 글자, _ 한 글자) | ENAME LIKE 'S%' |
| IS NULL / IS NOT NULL | NULL 확인 | COMM IS NULL |
| NOT, AND, OR | 논리 연산 | |

> 💡 **연산자 우선순위**: ( ) → 비교 연산자 → NOT → AND → OR. AND 가 OR 보다 먼저 계산돼요!

```sql
SELECT ENAME, SAL FROM EMP WHERE SAL BETWEEN 1250 AND 1600;
```

```sql
-- LIKE: 두 번째 글자가 A 인 이름
SELECT ENAME FROM EMP WHERE ENAME LIKE '_A%';
```

```sql
-- AND 가 먼저: (DEPTNO = 20 AND SAL > 2000) OR JOB = 'CLERK'
SELECT ENAME, DEPTNO, JOB, SAL FROM EMP
WHERE JOB = 'CLERK' OR DEPTNO = 20 AND SAL > 2000;
```

!> `NOT IN (목록)` 의 목록에 **NULL 이 있으면 결과가 하나도 나오지 않아요.** `DEPTNO NOT IN (10, NULL)` 은 `DEPTNO <> 10 AND DEPTNO <> NULL` 이고, NULL 비교는 UNKNOWN 이기 때문이에요.

```sql
SELECT COUNT(*) AS 건수 FROM EMP WHERE DEPTNO NOT IN (10, NULL);
```

## 03.5 | GROUP BY, HAVING 절

**집계 함수**(다중행 함수)는 여러 행을 묶어 값 하나를 만들어요: COUNT, SUM, AVG, MAX, MIN, STDDEV, VARIAN. **GROUP BY** 는 묶을 기준, **HAVING** 은 묶은 **그룹에 대한 조건**이에요.

```sql
-- 부서별 사원 수, 급여 합계·평균·최대
SELECT DEPTNO, COUNT(*) AS 인원, SUM(SAL) AS 합계, ROUND(AVG(SAL), 1) AS 평균, MAX(SAL) AS 최대
FROM EMP GROUP BY DEPTNO;
```

```sql
-- HAVING: 평균 급여가 2000 이상인 부서만
SELECT DEPTNO, ROUND(AVG(SAL), 1) AS 평균
FROM EMP GROUP BY DEPTNO HAVING AVG(SAL) >= 2000;
```

| 구분 | WHERE | HAVING |
|---|---|---|
| 대상 | 개별 행 | GROUP BY 로 묶은 그룹 |
| 집계 함수 사용 | 불가 | 가능 |
| 실행 시점 | GROUP BY 전 | GROUP BY 후 |

!> GROUP BY 를 쓰면 SELECT 절에는 **GROUP BY 칼럼과 집계 함수만** 올 수 있어요. `SELECT DEPTNO, ENAME, COUNT(*) FROM EMP GROUP BY DEPTNO` 는 오라클에서 오류입니다. (ENAME 이 그룹마다 여러 개라서)

> 💡 집계 함수는 NULL 을 빼고 계산하고, 대상이 하나도 없을 때 COUNT 는 0, 나머지(SUM, AVG…)는 NULL 을 돌려줘요.

```sql
SELECT COUNT(*) AS 건수, SUM(SAL) AS 합계 FROM EMP WHERE DEPTNO = 40;
```

## 03.6 | ORDER BY 절

결과를 **정렬**해요. 기본은 오름차순(ASC), 내림차순은 DESC. 칼럼 이름, **별칭**, **SELECT 절의 순서 번호**로 지정할 수 있어요.

```sql
-- 부서는 오름차순, 같은 부서 안에서는 급여 내림차순
SELECT DEPTNO, ENAME, SAL FROM EMP WHERE DEPTNO IN (10, 20) ORDER BY DEPTNO, SAL DESC;
```

```sql
-- 별칭과 위치 번호로 정렬
SELECT ENAME, SAL * 12 AS 연봉 FROM EMP WHERE DEPTNO = 10 ORDER BY 연봉 DESC;
SELECT ENAME, SAL FROM EMP WHERE DEPTNO = 10 ORDER BY 2;
```

> 💡 **NULL 의 정렬 위치**: 오라클은 NULL 을 **가장 큰 값**으로 봐서 오름차순이면 **맨 뒤**, SQL Server 는 가장 작은 값으로 봐서 맨 앞이에요. 오라클은 `NULLS FIRST / NULLS LAST` 로 바꿀 수 있어요.

```sql
-- 이 앱(SQLite)은 NULL 을 작은 값으로 본다 → NULLS LAST 로 오라클처럼
SELECT ENAME, COMM FROM EMP WHERE DEPTNO = 30 ORDER BY COMM NULLS LAST;
```

## 03.7 | 조인

**조인**은 여러 테이블을 이어서 하나처럼 조회하는 거예요. WHERE 절에 조인 조건을 쓰는 방식(오라클 방식)을 먼저 봅니다.

### 등가 조인 (EQUI JOIN)

```sql
SELECT E.ENAME, D.DNAME, D.LOC
FROM EMP E, DEPT D
WHERE E.DEPTNO = D.DEPTNO AND E.SAL >= 3000;
```

### 비등가 조인 (NON-EQUI JOIN)

= 가 아닌 조건(BETWEEN, >, < 등)으로 잇는 조인이에요. 급여로 급여 등급을 찾아봐요.

```sql
SELECT E.ENAME, E.SAL, S.GRADE
FROM EMP E, SALGRADE S
WHERE E.SAL BETWEEN S.LOSAL AND S.HISAL AND E.DEPTNO = 10;
```

### 3개 이상 테이블 조인

```sql
SELECT E.ENAME, D.DNAME, S.GRADE
FROM EMP E, DEPT D, SALGRADE S
WHERE E.DEPTNO = D.DEPTNO
  AND E.SAL BETWEEN S.LOSAL AND S.HISAL
  AND E.JOB = 'MANAGER';
```

> 💡 테이블 N 개를 조인하려면 조인 조건이 **최소 N-1 개** 필요해요. 조건을 빠뜨리면 모든 조합이 나오는 **카티션 곱**이 됩니다. (EMP 14건 × DEPT 4건 = 56건)

```sql
SELECT COUNT(*) AS 카티션곱 FROM EMP, DEPT;
```

### 오라클 외부 조인 (+)

조인 조건에 맞지 않는 행도 보여 주려면, **데이터가 없는 쪽**에 `(+)` 를 붙여요. (오라클 전용)

```sql norun
SELECT D.DEPTNO, D.DNAME, E.ENAME
FROM DEPT D, EMP E
WHERE D.DEPTNO = E.DEPTNO(+);      -- 사원이 없는 40번 부서도 나온다
```

## 03.8 | 표준 조인

ANSI 표준 조인은 조인 조건을 **FROM 절**에 써요. WHERE 에는 일반 조건만 남아 읽기 쉬워집니다.

| 조인 | 형식 | 특징 |
|---|---|---|
| INNER JOIN | A INNER JOIN B ON 조건 | 조건에 맞는 행만 (INNER 생략 가능) |
| NATURAL JOIN | A NATURAL JOIN B | **이름이 같은 모든 칼럼**으로 등가 조인, 별칭·ON 사용 불가 |
| USING | A JOIN B USING (칼럼) | 지정한 같은 이름 칼럼으로 조인, 그 칼럼에 별칭 불가 |
| LEFT OUTER JOIN | A LEFT JOIN B ON 조건 | 왼쪽 A 는 모두 + 오른쪽은 맞는 것만 (없으면 NULL) |
| RIGHT OUTER JOIN | A RIGHT JOIN B ON 조건 | 오른쪽 B 는 모두 |
| FULL OUTER JOIN | A FULL JOIN B ON 조건 | 양쪽 모두 |
| CROSS JOIN | A CROSS JOIN B | 카티션 곱 |

```sql
SELECT E.ENAME, D.DNAME FROM EMP E INNER JOIN DEPT D ON E.DEPTNO = D.DEPTNO WHERE D.DEPTNO = 10;
```

```sql
-- USING: 조인 칼럼 DEPTNO 에는 별칭을 붙이지 않는다
SELECT DEPTNO, E.ENAME, D.LOC FROM EMP E JOIN DEPT D USING (DEPTNO) WHERE DEPTNO = 10;
```

```sql
-- LEFT OUTER JOIN: 사원이 없는 40번 부서도 나온다
SELECT D.DEPTNO, D.DNAME, COUNT(E.EMPNO) AS 인원
FROM DEPT D LEFT OUTER JOIN EMP E ON D.DEPTNO = E.DEPTNO
GROUP BY D.DEPTNO, D.DNAME ORDER BY D.DEPTNO;
```

```sql
-- FULL OUTER JOIN: 양쪽에서 짝이 없는 행도 모두 (부서 없는 사원을 하나 추가해서 확인)
INSERT INTO EMP (EMPNO, ENAME, SAL) VALUES (9999, 'NEWBIE', 1000);
SELECT E.ENAME, D.DNAME FROM EMP E FULL OUTER JOIN DEPT D ON E.DEPTNO = D.DEPTNO
WHERE E.DEPTNO IS NULL OR D.DEPTNO = 40 OR E.EMPNO IS NULL;
```

> 💡 LEFT JOIN 에서 `COUNT(*)` 를 쓰면 40번 부서도 1 로 세어져요(NULL 로 채운 행 하나). 사원 수를 정확히 세려면 `COUNT(E.EMPNO)` 처럼 **오른쪽 테이블의 칼럼**을 세야 합니다.
