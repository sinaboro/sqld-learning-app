## 06.0 | 시험 안내와 활용법

| 항목 | 내용 |
|---|---|
| 과목 | 1과목 데이터 모델링의 이해 (10문항), 2과목 SQL 기본 및 활용 (40문항) |
| 시간 | 90분, 50문항 (객관식 4지선다) |
| 합격 기준 | 총점 **60점 이상** + 과목별 **40% 이상** (과락 주의) |

> 💡 대표 유형 30선 → 변형문제 01·02회 → 앱의 **실전 모의고사 01~05회** (과목 비율대로 50문항, 90분 타이머, 과락까지 채점) 순서로 풀어 보세요. 틀린 문제는 해설의 장·절로 돌아가 다시 읽는 것이 가장 빠른 길이에요. 시험 출제 범위와 비율은 바뀔 수 있으니 시험 전에 한국데이터산업진흥원 공지를 꼭 확인하세요.

+ 계산할 그룹(파티션)을 나눈다
- 행 수를 줄인다
- 중복을 제거한다
= 파티션별로 따로 계산하되 행 수는 그대로예요.
? 다음 SQL 에서 KING(5000) 의 결과 값은? (부서 10: MILLER 1300, CLARK 2450, KING 5000)
```sql

FROM EMP WHERE DEPTNO = 10;
```
- 5000
- 6300
+ 8750
- 3750
= 급여 오름차순 누적합: 1300 → 3750 → 8750 이에요.
? 셀프 조인에 대한 설명으로 옳은 것은?
+ 같은 테이블에 서로 다른 별칭을 붙여 조인한다
- 반드시 외부 조인이어야 한다
- 별칭을 쓰지 않는다
- 서로 다른 두 테이블만 가능하다
= 같은 테이블을 두 번 쓰려면 별칭으로 구분해요.
? PIVOT 절에 대한 설명으로 옳지 않은 것은?
- 행 데이터를 열로 바꾼다
- 집계 함수와 FOR 절을 쓴다
+ GROUP BY 를 반드시 직접 써야 한다
- IN 절에 열로 만들 값을 지정한다
= PIVOT 은 나머지 칼럼으로 자동 그룹화해요.
? DELETE 와 TRUNCATE 에 대한 설명으로 옳은 것은?
- 둘 다 DML 이다
+ DELETE 는 롤백할 수 있고 TRUNCATE 는 오라클에서 롤백할 수 없다
- TRUNCATE 는 WHERE 절을 쓸 수 있다
- DELETE 는 테이블 구조까지 지운다
= TRUNCATE 는 DDL 이라 자동 커밋돼요.
? FOREIGN KEY 에 ON DELETE SET NULL 옵션을 주면 부모 행을 삭제할 때?
- 자식 행도 삭제된다
+ 자식 행의 외래키 값이 NULL 이 된다
- 삭제가 거부된다
- 부모 행만 남는다
= 자식의 FK 를 NULL 로 바꿔요.
@end

- 데이터 독립성은 중복을 늘린다
= 논리적 독립성: 개념 ↔ 외부, 물리적 독립성: 내부 ↔ 개념이에요.
? 다음 중 M:N 관계를 해소하기 위해 만드는 것은?

- 파생 속성

? 비식별자 관계를 선택하기에 알맞은 경우는?
- 부모가 반드시 있어야만 자식이 생길 때
+ 자식의 주식별자를 부모와 독립적으로 구성하고 싶을 때
- 부모 키로 자식을 바로 조회해야 할 때
- 관계가 매우 강할 때
= 약한 관계이거나 자식 PK 를 독립적으로 두고 싶을 때 비식별자 관계를 써요.
? 트랜잭션의 성질과 설명이 틀린 것은?
- 원자성 - 모두 실행되거나 모두 취소된다
- 일관성 - 실행 전후 일관된 상태를 유지한다
+ 고립성 - 커밋된 결과는 영구히 저장된다
- 지속성 - 커밋된 결과는 장애가 나도 유지된다
= '영구 저장'은 지속성이에요. 고립성은 다른 트랜잭션의 간섭을 받지 않는 것이에요.
