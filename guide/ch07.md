## 07.1 | SQLD 고난이도 예상문제

@quiz s=2
? 예제 DB 에서 다음 SQL 의 결과는?
```sql
SELECT COUNT(*) FROM EMP WHERE COMM NOT IN (300, 500, NULL);
```
- 2
- 8
+ 0
- 12
= NOT IN 목록에 NULL 이 있으면 모든 행의 조건이 UNKNOWN 이 되어 0 건이에요.
? 예제 DB 에서 다음 SQL 의 결과는?
```sql
SELECT COUNT(*) FROM EMP WHERE COMM IN (300, 500, NULL);
```
- 0
+ 2
- 3
- 12
= IN 은 OR 로 바뀌어 COMM = 300 OR COMM = 500 OR COMM = NULL. NULL 비교는 무시되고 2건이 나와요.
? 다음 두 SQL 의 결과 행 수는? (예제 DB)
```sql
SELECT D.DEPTNO, E.ENAME FROM DEPT D LEFT JOIN EMP E ON D.DEPTNO = E.DEPTNO AND E.SAL > 3000;
SELECT D.DEPTNO, E.ENAME FROM DEPT D LEFT JOIN EMP E ON D.DEPTNO = E.DEPTNO WHERE E.SAL > 3000;
```
+ 4행, 1행
- 1행, 1행
- 4행, 4행
- 15행, 1행
= ON 의 조건은 조인할 짝만 거르고 DEPT 는 모두 남아 4행(10번만 KING, 나머지 NULL). WHERE 는 조인 뒤 거르므로 KING 1행이에요.
? 예제 DB 에서 다음 SQL 의 결과는?
```sql
SELECT COUNT(*) FROM EMP WHERE SAL > ALL (SELECT SAL FROM EMP WHERE DEPTNO = 40);
```
- 0
+ 14
- 1
- 오류
= 서브쿼리 결과가 비어 있으면 > ALL 은 참이 되어 모든 행(14건)이 나와요. > ANY 였다면 0건이에요.
? 다음 중 결과가 나머지와 다른 것은? (COMM 은 NULL 이 있는 칼럼)
- SELECT SUM(COMM) FROM EMP
- SELECT SUM(NVL(COMM, 0)) FROM EMP
+ SELECT SUM(COMM + 0) FROM EMP WHERE COMM IS NULL
- SELECT SUM(COMM) FROM EMP WHERE COMM IS NOT NULL
= NULL 인 행만 더하면 결과는 NULL 이에요. 나머지는 모두 2200 이에요.
? 예제 DB 에서 다음 SQL 의 결과 행 수는?
```sql
SELECT DEPTNO, JOB, SUM(SAL) FROM EMP
GROUP BY GROUPING SETS ((DEPTNO, JOB), ());
```
- 9
+ 10
- 13
- 14
= (부서, 업무) 조합 9개(10번 3, 20번 3, 30번 3) + 전체 합계 1행 = 10행이에요.
? 예제 DB 에서 다음 SQL 의 결과는?
```sql
SELECT COUNT(*) FROM EMP E1
WHERE 3 > (SELECT COUNT(*) FROM EMP E2 WHERE E2.SAL > E1.SAL);
```
+ 3
- 4
- 5
- 2
= 나보다 급여가 높은 사원이 3명 미만인 사원을 세요. KING(0명), SCOTT(1명), FORD(1명)는 해당하고, JONES 는 위에 KING·SCOTT·FORD 3명이 있어 제외돼요. 동점자(SCOTT·FORD)가 있어 '상위 3명'이 정확히 3명으로 나오는 연관 서브쿼리 TOP-N 패턴이에요.
? ROWNUM 에 대한 다음 SQL 중 결과가 한 건 이상 나오는 것은? (오라클)
+ SELECT * FROM EMP WHERE ROWNUM < 3
- SELECT * FROM EMP WHERE ROWNUM = 2
- SELECT * FROM EMP WHERE ROWNUM > 1
- SELECT * FROM EMP WHERE ROWNUM BETWEEN 2 AND 3
= ROWNUM 은 1부터 순서대로 매겨져 1을 포함하지 않는 조건은 결과가 없어요.
? 윈도우 함수에서 ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING 의 뜻은?
- 처음부터 현재 행까지
+ 현재 행과 바로 앞·뒤 한 행씩, 최대 3행
- 앞의 모든 행
- 현재 행만
= 이동 평균 같은 계산에 써요.
? 오라클 계층형 질의에서 WHERE 절의 조건은 언제 적용되나요?
- 계층 전개 전에 START WITH 대상만 거른다
+ 계층 전개가 모두 끝난 뒤 결과 행을 거른다
- CONNECT BY 조건과 똑같이 동작한다
- 루트 행에만 적용된다
= WHERE 는 전개 후 필터라서 중간 노드를 빼도 그 자식은 남아요. 가지째 빼려면 CONNECT BY 절에 조건을 둬요.
? UNION 으로 합친 결과를 정렬할 때 올바른 것은?
- 각 SELECT 마다 ORDER BY 를 쓴다
+ 마지막 SELECT 뒤에 ORDER BY 를 한 번 쓴다
- 첫 SELECT 에만 ORDER BY 를 쓴다
- UNION 결과는 정렬할 수 없다
= 집합 연산 전체에 대해 맨 끝에 한 번만 써요.
? TRUNCATE 와 DELETE(조건 없음)에 대한 설명으로 틀린 것은?
- 둘 다 모든 행을 지운다
- TRUNCATE 가 보통 더 빠르다
+ 둘 다 오라클에서 롤백할 수 있다
- TRUNCATE 는 저장 공간을 반납한다
= TRUNCATE 는 DDL 이라 오라클에서 롤백할 수 없어요.
@end

## 07.2 | SQL 실습 문제

예제 DB(EMP, DEPT, SALGRADE)로 직접 SQL 을 써 보는 문제예요. 앱에서는 SQL 을 입력하고 **[채점]** 을 누르면 정답 SQL 의 결과와 비교해 맞았는지 알려 줘요. (행의 순서는 정답에 ORDER BY 가 있을 때만 비교해요)

@task 1. 급여 3000 이상
급여(SAL)가 3000 이상인 사원의 이름(ENAME)과 급여를 조회하세요.
```sql
SELECT ENAME, SAL FROM EMP WHERE SAL >= 3000;
```
@end

@task 2. 커미션을 받는 사원
커미션(COMM)이 NULL 이 아닌 사원의 이름, 급여, 커미션을 조회하세요.
```sql
SELECT ENAME, SAL, COMM FROM EMP WHERE COMM IS NOT NULL;
```
@end

@task 3. 연봉 계산
모든 사원의 이름과 연봉(SAL * 12 + 커미션, 커미션이 없으면 0으로)을 연봉이 높은 순으로 조회하세요. 연봉 칼럼 이름은 연봉 으로 하세요.
```sql
SELECT ENAME, SAL * 12 + NVL(COMM, 0) AS 연봉 FROM EMP ORDER BY 연봉 DESC, ENAME;
```
@end

@task 4. 이름 패턴
이름이 S 로 시작하거나 이름에 'AR' 이 들어가는 사원의 이름을 조회하세요.
```sql
SELECT ENAME FROM EMP WHERE ENAME LIKE 'S%' OR ENAME LIKE '%AR%';
```
@end

@task 5. 부서별 인원과 평균
부서번호별 사원 수와 평균 급여(소수 첫째 자리까지 반올림)를 부서번호 순으로 조회하세요.
```sql
SELECT DEPTNO, COUNT(*) AS 인원, ROUND(AVG(SAL), 1) AS 평균 FROM EMP GROUP BY DEPTNO ORDER BY DEPTNO;
```
@end

@task 6. 업무별 최고 급여 (HAVING)
업무(JOB)별 최고 급여를 구하되, 최고 급여가 2000 이상인 업무만 조회하세요.
```sql
SELECT JOB, MAX(SAL) AS 최고 FROM EMP GROUP BY JOB HAVING MAX(SAL) >= 2000;
```
@end

@task 7. 사원과 부서 이름
사원 이름과 그 사원의 부서 이름(DNAME), 근무지(LOC)를 조회하세요.
```sql
SELECT E.ENAME, D.DNAME, D.LOC FROM EMP E JOIN DEPT D ON E.DEPTNO = D.DEPTNO;
```
@end

@task 8. 사원이 없는 부서까지
모든 부서의 부서번호, 부서 이름, 사원 수를 부서번호 순으로 조회하세요. 사원이 없는 부서는 0명으로 나와야 해요.
```sql
SELECT D.DEPTNO, D.DNAME, COUNT(E.EMPNO) AS 인원 FROM DEPT D LEFT JOIN EMP E ON D.DEPTNO = E.DEPTNO GROUP BY D.DEPTNO, D.DNAME ORDER BY D.DEPTNO;
```
@end

@task 9. 급여 등급
사원 이름, 급여, 급여 등급(SALGRADE 의 GRADE)을 조회하세요.
```sql
SELECT E.ENAME, E.SAL, S.GRADE FROM EMP E JOIN SALGRADE S ON E.SAL BETWEEN S.LOSAL AND S.HISAL;
```
@end

@task 10. 관리자 이름
사원 이름과 그 관리자의 이름을 조회하세요. 관리자가 없는 사원(KING)도 나와야 하고, 관리자 칼럼 이름은 관리자 로 하세요.
```sql
SELECT W.ENAME, M.ENAME AS 관리자 FROM EMP W LEFT JOIN EMP M ON W.MGR = M.EMPNO;
```
@end

@task 11. 평균보다 많이
전체 평균 급여보다 급여가 많은 사원의 이름과 급여를 조회하세요. (서브쿼리)
```sql
SELECT ENAME, SAL FROM EMP WHERE SAL > (SELECT AVG(SAL) FROM EMP);
```
@end

@task 12. 부서 최고 급여자
각 부서에서 급여가 가장 높은 사원의 부서번호, 이름, 급여를 조회하세요.
```sql
SELECT DEPTNO, ENAME, SAL FROM EMP E WHERE SAL = (SELECT MAX(SAL) FROM EMP WHERE DEPTNO = E.DEPTNO);
```
@end

@task 13. 부서 안 급여 순위
사원 이름, 부서번호, 급여, 부서 안에서의 급여 순위(RANK, 높은 급여가 1위)를 부서번호·순위 순으로 조회하세요. 순위 칼럼 이름은 순위 로 하세요.
```sql
SELECT ENAME, DEPTNO, SAL, RANK() OVER (PARTITION BY DEPTNO ORDER BY SAL DESC) AS 순위 FROM EMP ORDER BY DEPTNO, 순위, ENAME;
```
@end

@task 14. 급여 상위 5명
급여가 높은 순으로 5명의 이름과 급여를 조회하세요. 급여가 같으면 이름순으로 하세요.
```sql
SELECT ENAME, SAL FROM EMP ORDER BY SAL DESC, ENAME LIMIT 5;
```
@end

@task 15. 업무별 부서 급여표 (PIVOT 흉내)
업무별로 10, 20, 30번 부서의 급여 합계를 열(D10, D20, D30)로 보여 주세요. 업무 이름 순으로 정렬하세요.
```sql
SELECT JOB, SUM(CASE WHEN DEPTNO = 10 THEN SAL END) AS D10, SUM(CASE WHEN DEPTNO = 20 THEN SAL END) AS D20, SUM(CASE WHEN DEPTNO = 30 THEN SAL END) AS D30 FROM EMP GROUP BY JOB ORDER BY JOB;
```
@end
