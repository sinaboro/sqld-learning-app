# SQLD 첫걸음 — 학습 교안 + 학습 앱

SQLD(SQL 개발자) 시험을 처음 준비하는 사람을 위한 **학습 교안(PDF)**과, 같은 내용을 폰에서 공부하는 **학습 앱**입니다.
교안의 SQL 예제는 모두 예제 DB 에서 실제로 실행한 결과를 실었고, 앱에서는 SQL 을 **직접 고쳐 실행**하고 **실전 모의고사**와 **SQL 실습 채점**을 할 수 있어요.

## 📱 학습 앱

- **SQL 실행**: 검은 SQL 상자를 고쳐서 ▶ 실행. 브라우저 안의 SQLite(sql.js)에 예제 DB 가 들어 있어요. 처음 한 번만 실행기(약 1MB)를 받고, 그 뒤로는 인터넷 없이도 실행돼요.
- **확인 문제**: 절마다 바로 채점·해설, 진도 기록
- **실전 모의고사 01~05회**: 50문항(1과목 10 · 2과목 40), 90분 타이머, 문항당 2점, **과락까지 채점**(60점 이상 + 과목별 40% 이상), 문항별 해설과 출처. 문제 은행에서 회차마다 다르게 뽑아요.
- **SQL 실습**: 문제를 보고 SQL 을 써서 **채점** — 정답 SQL 의 결과와 비교해서 칼럼 수·행 수·값을 알려 줘요.
- NVL, NVL2, DECODE, LPAD/RPAD, INITCAP, TRUNC, ROUND(음수 자릿수), MOD, REGEXP_LIKE/SUBSTR/REPLACE/INSTR/COUNT 는 오라클처럼 동작하게 넣어 두었어요.
- ROLLUP·CUBE, CONNECT BY, PIVOT, MERGE, ROWNUM, (+) 외부 조인 같은 **오라클 전용 문법**은 SQLite 에서 실행되지 않아요. 교안·앱 모두 그런 예제 바로 아래에 **같은 결과를 내는 표준 SQL**(UNION ALL, WITH RECURSIVE, CASE, ON CONFLICT, ROW_NUMBER, LEFT JOIN)을 함께 실었어요.

### 설치 방법 (가장 쉬운 방법: 카카오톡)
1. 카카오톡으로 받은 링크 `https://sinaboro.github.io/sqld-learning-app/` 를 누릅니다.
2. 앱이 **자동으로 Chrome(아이폰은 Safari)으로 넘어갑니다.** 안 넘어가면 위쪽 안내의 **[Chrome으로 열기]** 를 누릅니다.
3. 화면 위쪽 **"홈 화면에 앱으로 설치하면…"** 안내의 **[설치]** → 확인 창에서 **설치**.
   - 안내가 안 보이면 Chrome **`⋮` → 앱 설치(홈 화면에 추가)** · 아이폰은 Safari **공유 → 홈 화면에 추가**
4. 홈 화면에 **SQLD** 아이콘이 생깁니다. 인터넷이 될 때 한 번 열고 SQL 도 한 번 실행해 두면 비행기 모드에서도 공부할 수 있어요.

새 내용이 추가되면 인터넷이 될 때 앱을 열면 **자동으로 업데이트**됩니다. 진도·모의고사 기록은 그대로 남아요.

## 🛠 내용을 고치거나 추가하려면

원고는 `guide/ch01~07.md` **한 곳**에만 있고, 교안 PDF 와 앱은 여기서 자동으로 만들어집니다.

```
pip install reportlab pillow
python tools/build_pdf.py          # 교안 PDF (SQL 을 예제 DB 에서 실제로 실행해 결과 표를 넣음)
python tools/build_app.py --bump   # 앱 내용 docs/content.js + 앱 버전 올리기
```

| 파일·폴더 | 설명 |
|---|---|
| `guide/ch01~07.md` | 원고. 문법은 `tools/sql_lib.py` 맨 위 설명 참고 |
| `guide/sample_db.sql` | 예제 DB (교안·앱·실습 공통) |
| `tools/sql_lib.py` | 원고 읽기 + SQL 실행 + 오라클 함수 흉내 (공통) |
| `tools/build_pdf.py` / `build_app.py` / `make_icons.py` | 교안 PDF / 앱 데이터 / 아이콘 |
| `docs/` | 앱 (GitHub Pages). `app.js` 기능, `content.js` 자동 생성 내용, `sw.js` 오프라인 |
